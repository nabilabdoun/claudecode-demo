# Claude Code Demo Project

This is a simple Python project used to demonstrate how to work with Claude Code step by step.

## Project Goal

Improve a simple login function using Claude Code.

## Files

- app.py: contains the login function
- CLAUDE.md: contains the rules Claude should follow
- README.md: explains the project

## How to Run

Open the project folder in Windows Terminal and run:

```bash
python app.py
